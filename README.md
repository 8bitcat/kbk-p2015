# Stödmedlem KBK P2015

Stödmedlemssida för Kungsladugårds BK P2015. Välj belopp, så får du en färdig
Swish-länk (mobil) eller QR-kod (dator) med lagets nummer, belopp och meddelande
ifyllt. Allt stöd går till hela laget, det finns inget val av enskild spelare.

Live: https://8bitcat.github.io/kbk-p2015/

- `index.html` – hela sidan, byggd av `bygg.py` från källan på Skrivbordet
  (tavlan `INBETALNINGAR`/`MAL`/`UPPDATERAD` i skriptet)
- `bilder/` – klubbmärke och lagbild från lagets sida på kungsladugardsbk.se
