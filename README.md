# Stödmedlem KBK P2015

Stödmedlemssida för Kungsladugårds BK P2015. Välj belopp och vem du hejar på,
så får du en färdig Swish-länk (mobil) eller QR-kod (dator) med lagets nummer,
belopp och meddelande ifyllt.

Live: https://8bitcat.github.io/kbk-p2015/

- `index.html` – hela sidan, byggd av `bygg.py` från källan på Skrivbordet
  (spelarlistan `SPELARE`, tavlan `INBETALNINGAR`/`MAL`/`UPPDATERAD` i skriptet)
- `bilder/` – klubbmärke och lagbild från lagets sida på kungsladugardsbk.se
